# Versta — сайт веб-студии

Двуязычный (UA / EN) сайт студии с шестью рабочими демо, калькулятором стоимости и портфолио.
Стек: **React 19 + TypeScript + Vite**, собственная CSS-дизайн-система, SVG-графика без внешних библиотек.
Сборка полностью статическая — подходит для бесплатного Cloudflare Pages.

---

## 1. Что где редактировать

| Что | Файл |
|---|---|
| Название студии, домен, контакты (Telegram, WhatsApp, email, телефон), данные для юридических страниц, адрес отправки формы | `src/config/site.json` |
| **Все цены, стартовая акция, тарифы обслуживания и их условия** (UA — гривны, EN — евро) | `src/config/pricing.ts` |
| Все тексты сайта | `src/i18n/uk.ts` (украинский) и `src/i18n/en.ts` (английский) |
| SEO-заголовки и описания страниц | `src/i18n/seo.json` |
| Портфолио (концепт-проекты) | `src/pages/cases.ts` |
| Цвета, шрифты, сетка | `src/styles/base.css` (переменные в `:root`) |

**Контакты.** Пустые поля в `site.json` автоматически скрываются. Пока ни одного контакта нет, сайт показывает подсказку «заполните site.json» — заполните перед публикацией.

**Цены, акция и обслуживание.** Всё в одном файле `src/config/pricing.ts`:
- `promo.enabled` — стартовая акция. Поставьте `false` и пересоберите: зачёркнутые цены, экономия, «−43%» и надписи об акции исчезнут со всех страниц и из калькулятора, останутся стандартные цены.
- `promo.factor` — коэффициент стартовой цены (4/7 ≈ скидка 43%). Для 10 позиций прайса стартовые цены заданы явно (`promo`), для доп. страниц, языков, функций и анимаций считаются через коэффициент.
- `ITEMS` — позиции прайса (названия, сроки, сколько страниц входит), `PLANS` — тарифы BASIC / STANDARD / BUSINESS, `COMPARE` — таблица сравнения, `TERMS` — условия обслуживания (тексты на обоих языках).
- Блок `uk` — гривны, блок `en` — евро, цены редактируются независимо.

Евро-цены — моё предложение: стартовые цены разработки взяты из ваших прежних ориентиров (лендинг от 200 €, многостраничный от 400 €), стандартные — по той же пропорции; тарифы обслуживания €19 / €49 / €99 в месяц. Проверьте и поправьте под рынок.

**Домен.** Замените `"domain": "https://example.com"` в `site.json` на реальный — от него строятся canonical, hreflang, Open Graph и sitemap.

## 2. Локальный запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в dist/ + генерация SEO-страниц, sitemap, robots, 404
npm run preview    # просмотр собранной версии
```

Нужен Node.js 20+.

## 3. Публикация на Cloudflare

Проект развёрнут как **Cloudflare Worker со статическими файлами** (`wrangler.jsonc`): сайт отдаётся из `dist/`, а `worker/index.js` обрабатывает только `POST /api/lead` (отправка заявок). Подключение к GitHub: Workers & Pages → проект → Settings → Build — Build command `npm run build`, Deploy command `npx wrangler deploy`. Каждый push в `main` публикуется автоматически.

Папка `functions/` оставлена для совместимости: если когда-нибудь развернуть проект как Cloudflare Pages, отправка заявок тоже будет работать.


### Вариант А — через GitHub (рекомендуется, обновления автоматические)

1. Залейте проект в репозиторий на GitHub.
2. Cloudflare Dashboard → **Workers & Pages → Create → Pages → Connect to Git** → выберите репозиторий.
3. Настройки сборки:
   - Framework preset: **None** (или Vite)
   - Build command: `npm run build`
   - Build output directory: `dist`
   - Environment variable: `NODE_VERSION` = `22`
4. **Save and Deploy.** Сайт появится на `имя-проекта.pages.dev`.

### Вариант Б — без Git (просто загрузить папку)

Папка `dist/` в архиве уже собрана. Workers & Pages → Create → Pages → **Upload assets** → перетащите содержимое `dist/`.
(Функция отправки формы из `functions/` при таком способе не загружается — для неё нужен вариант А или `npx wrangler pages deploy dist`.)

### Подключение своего домена

1. Проект в Pages → **Custom domains → Set up a custom domain** → введите `вашдомен.com`.
2. Если домен уже в Cloudflare — DNS-запись создастся автоматически. Если домен у другого регистратора — либо перенесите NS-серверы в Cloudflare (проще всего), либо добавьте у регистратора CNAME `www` → `имя-проекта.pages.dev`.
3. SSL выпускается автоматически (обычно за несколько минут).
4. Не забудьте обновить `domain` в `site.json` и пересобрать.

## 4. Форма заявки

Сейчас `"endpoint": ""` — форма **честно сообщает**, что не подключена, и предлагает скопировать текст и написать напрямую. Ложного «Успешно отправлено» нет.

**Заявки в Telegram и на почту (бесплатно, уже настроено в проекте).** В `site.json` стоит `"endpoint": "/api/lead"` — форма отправляет заявку функции `functions/api/lead.js`, а та пересылает её в Telegram и на email. Нужно только добавить секреты в Cloudflare → проект → **Settings → Variables and Secrets** (тип *Secret*) и сделать повторный деплой:

| Переменная | Где взять |
|---|---|
| `TELEGRAM_BOT_TOKEN` | [@BotFather](https://t.me/BotFather) → `/newbot` |
| `TELEGRAM_CHAT_ID` | напишите [@userinfobot](https://t.me/userinfobot) — он пришлёт ваш Id. Затем обязательно нажмите **Start** в своём новом боте |
| `RESEND_API_KEY` | [resend.com](https://resend.com) → API Keys (бесплатно: 100 писем в день) |
| `LEAD_EMAIL_TO` | ваша почта — **та же**, с которой вы зарегистрировались в Resend (без своего домена Resend отправляет только на неё) |
| `LEAD_EMAIL_FROM` | необязательно: после подтверждения своего домена в Resend, напр. `Versta <leads@вашдомен.com>` |

Каналы независимы: если настроен только Telegram, работает только он. Посетитель видит «Заявку отримано» лишь тогда, когда заявку действительно принял хотя бы один канал; если не настроен ни один — форма честно сообщает об ошибке и предлагает написать напрямую.

**Альтернатива:** любой сервис форм (Formspree, Web3Forms и т.п.) — укажите его URL в `endpoint`, а нужные ключи — в `extraFields`.

## 5. Что внутри

- **Главная:** «живой макет» — настоящий мини-сайт, который перестраивается под ширину при перетаскивании края (container queries), с режимом «Каркас / Дизайн».
- **Услуги:** 9 разделов с пользой для бизнеса простым языком, «от …» из `pricing.ts`.
- **Demo Lab:** 6 демо, у каждого свой дизайн. Данные демонстрационные, хранятся только в `localStorage` браузера, кнопка «Скинуть демо» всё очищает. Платежей, отправки заказов и сбора данных нет.
  1. Analytics — фильтр дат, сравнение периодов, графики, экспорт CSV
  2. Booking — услуга → мастер → дата/время → подтверждение, перенос, отмена, календарь администратора
  3. Digital Menu — категории, поиск, фильтры, добавки, корзина, статус заказа
  4. CRM — клиенты, карточка и история, добавление/редактирование, канбан с drag & drop (мышь и палец — за значок ⋮⋮), прогноз выручки, задачи и напоминания
  5. E-commerce — каталог, фильтры, цвета/размеры, избранное, промокоды (`LEN10`, `WELCOME15`, `FREESHIP`), оформление
  6. Real Estate — фильтры цены/площади/комнат, галерея, сравнение до 3 квартир, ориентировочный ипотечный калькулятор, запись на просмотр
- **Страница «Ціни»** (`/pricing`): стартовые цены на 10 видов сайтов (стандартная цена зачёркнута), три тарифа обслуживания с таблицей сравнения и условия. Клик по строке прайса открывает калькулятор с этим типом сайта, «Обрати тариф» — форму с уже выбранным тарифом.
- **Калькулятор:** 10 типов сайтов, стандартная и стартовая цена, экономия, выбор тарифа обслуживания (или без него). Разработка (разово) и обслуживание (в месяц и за год) показаны отдельно. Расчёт можно скопировать, отправить в Telegram/email или перенести в форму вместе с тарифом.
- **Портфолио:** 6 концепт-кейсов с честной пометкой Concept.
- **Юридические страницы:** политика конфиденциальности и условия — шаблоны с полями из `site.json`.

## 6. SEO и доступность

- Для каждой страницы и языка при сборке генерируется отдельный HTML с `<title>`, description, canonical, `hreflang` (uk/en/x-default) и Open Graph — соцсети и поисковики видят правильные теги без выполнения JS.
- Украинская версия — `/`, английская — `/en/`. Выбранный язык сохраняется.
- `sitemap.xml`, `robots.txt`, `404.html`, favicon (SVG + PNG), `og-image.png`, web manifest.
- Структурированные данные (JSON-LD `ProfessionalService`) на главной — контакты попадают туда автоматически, когда заполнены в `site.json`.
- Семантическая разметка, skip-link, видимый фокус, aria-атрибуты, `prefers-reduced-motion`.
- Все модальные окна, шторки и меню закрываются клавишей Esc, фокус уходит внутрь окна и возвращается на кнопку, которая его открыла; Tab не «выпадает» из открытого окна.
- Контраст текста проверен по WCAG AA (4.5:1 для обычного текста) на сайте и во всех демо.
- Внешний шрифт подключён без блокировки отрисовки: текст виден сразу, шрифт подменяется по готовности.

## 7. Что важно знать честно

- **Lighthouse не замерялся** — в среде разработки это было невозможно. Проект собран с прицелом на 90+: статический HTML, код демо грузится отдельно по требованию, без тяжёлых библиотек. Проверьте после деплоя: Chrome DevTools → Lighthouse.
- **Сборка через Vite не запускалась** — в среде разработки не было доступа к npm. Код собирался и тестировался эквивалентным сборщиком (esbuild, `scripts/build-local.mjs`) и проверен в Chrome: все страницы на двух языках, десктоп и мобильный, клики по всем демо — без ошибок в консоли. Если `npm run build` на Cloudflare вдруг упадёт — `node scripts/build-local.mjs && node scripts/postbuild.mjs` даёт тот же результат.
- **Фото.** Все изображения сейчас — SVG-иллюстрации (лёгкие и чёткие). Реальных фото нет; если добавите — кладите в `public/img/` в WebP/AVIF.
- **Шрифты** Onest и JetBrains Mono грузятся с Bunny Fonts (GDPR-friendly зеркало Google Fonts). Для полной автономии можно скачать woff2 в `public/fonts` и заменить `<link>` в `index.html` на `@font-face`.
- **Юридические тексты** — согласованы с юристом владельца (ноябрь 2026). Impressum удалён (работа по Украине). Если бизнес ведётся из Германии, он обязателен по § 5 DDG — страницу можно вернуть из истории git. Проверьте тексты с юристом.
